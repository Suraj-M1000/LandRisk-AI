ABOUT THE PROJECT

Understanding Project Risk Through Data

LandRisk AI is a personal portfolio and learning project that explores how web development, data analysis, and machine learning can be combined to study infrastructure project risks.

THE PROBLEM

Why Project Risk Monitoring Matters

Infrastructure projects involve budgets, schedules, physical progress, expenditure, contractors, and sometimes land acquisition. Changes in these factors can make project monitoring more challenging.

LandRisk AI explores whether recorded project information can be used to estimate potential delay risk and present the results in a structured, understandable interface.

PROJECT OBJECTIVES

What This Project Aims to Demonstrate

  • Data handling: Organize project information and validate user inputs.
  • Machine learning: Integrate a trained classification pipeline into a Django application.
  • Interpretability: Present risk estimates, warnings, and available explanations in a user-friendly format.
  • Full-stack development: Connect frontend templates, backend views, database models, authentication, and ML inference.
  • Responsible evaluation: Document data limitations and distinguish experimental results from validated real-world predictions.
TECHNOLOGY STACK

How LandRisk AI Is Built

The application combines web technologies, data processing, machine learning, and visualization.

01

Backend

Django and Python handle request processing, application logic, authentication, and database interactions.

02

Database

Django models store project details and historical prediction records, including snapshots of the inputs used for each assessment.

03

Machine Learning

Scikit-learn provides the trained pipeline used by the separate Python inference module to generate experimental risk estimates.

04

Frontend

HTML, CSS, JavaScript, and Chart.js support the user interface, responsive layouts, interactive filters, and dashboard visualizations.

METHODOLOGY

From Data to an Application

1

Explore the Problem

Define the project-risk problem, examine data availability, and identify relevant project attributes.

2

Develop the ML Pipeline

Prepare the data, train a classification model, evaluate its behavior, and save the required inference artifacts.

3

Integrate with Django

Connect the model to project records through a separate inference module and save assessment results in the database.

4

Build and Test the Interface

Provide project management, prediction history, monitoring indicators, dashboard charts, authentication, and automated tests.

Limitations and Responsible Use

The current model uses synthetic training data because a verified, suitable public row-level dataset was not established for this prediction task. Its predictions have not been validated against real-world project outcomes. Therefore, this application demonstrates a technical workflow rather than a proven forecasting system. Its results should not be used for actual government, infrastructure, or financial decisions.
