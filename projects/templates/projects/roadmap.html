THE ROAD AHEAD

What's Next for LandRisk AI?

The project will evolve from an experimental risk-assessment prototype into a more comprehensive project-monitoring and predictive analytics platform through measurable, data-driven improvements.

FUTURE DEVELOPMENT

Planned Improvements

These are proposed enhancements, not features currently available in the application.

01 Planned

Delay-Duration Prediction

Explore regression models to estimate the potential delay duration in months, complementing the existing experimental risk assessment.

Key requirement: A credible dataset containing actual delay durations and relevant project features.

02 Planned

Project Progress Trends

Track changes in physical progress and expenditure across dated project snapshots to help users inspect how project conditions evolve over time.

Key requirement: Reliable, dated historical project records.

03 Planned

Model Evaluation & Improvement

Investigate stronger validation methods, compare suitable algorithms, assess classification metrics, and examine how well model outputs generalize to unseen projects.

Key requirement: Representative labelled data and leakage-aware evaluation.

04 Planned

Richer Risk Explanations

Improve how assessment results communicate influential project factors, uncertainty, and possible monitoring actions to users.

Goal: Make model outputs easier to interpret without presenting associations as proof of causation.

05 Planned

Project Reports & Data Export

Explore downloadable project summaries containing recorded details, monitoring indicators, and prediction history for review and documentation.

Goal: Make project information easier to share and review.

06 Planned

More Credible Training Data

Investigate suitable public infrastructure datasets and document their sources, limitations, and suitability for the prediction task.

Goal: Establish a defensible foundation for future model evaluation.

DEVELOPMENT PRINCIPLES

Build Responsibly, Improve with Evidence

Future features will be prioritized according to feasibility, data availability, evaluation quality, and user value. A more complex model is not automatically a better model: reliable data and honest evaluation matter more than adding algorithms without evidence.

Current Project Status

LandRisk AI is an educational prototype. Its current risk model uses synthetic training data and has not been validated for real-world forecasting. The items on this roadmap are proposals for future development and should not be interpreted as existing functionality or committed delivery dates.
