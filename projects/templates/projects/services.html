WHAT LANDRISK AI OFFERS

Project Monitoring & Risk Assessment

LandRisk AI brings project information, experimental machine learning risk assessments, and historical results together in one application.

CURRENT FEATURES

What You Can Do

The application supports the following project-monitoring and risk-analysis activities.

01

Project Management

Create projects and record details such as sector, state, estimated cost, planned duration, progress, expenditure, contractor experience, and land acquisition. Update or delete your own project records when needed.

02

ML-Based Risk Assessment

Run the integrated machine learning pipeline using the recorded project information. Review the estimated delay-risk probability and risk score.

03

Risk Explanations

Review the available explanations and warnings associated with an assessment to understand which recorded factors may contribute to the estimated risk.

04

Prediction History

Save assessment results and revisit previous predictions for a project. Compare recorded assessments over time as new assessments are generated.

05

Project Monitoring Indicators

Inspect indicators such as schedule utilization, the difference between expenditure and physical progress, and the application's heuristic schedule status.

06

Dashboard & Analytics

View project summaries, risk distributions, progress and expenditure comparisons, and schedule-status visualizations from the dashboard.

HOW TO USE THE APPLICATION

From Project Entry to Risk Insights

1

Create an Account

Sign up and log in to access your project workspace.

2

Add Project Details

Enter the project's cost, schedule, progress, expenditure, and other required information.

3

Run a Risk Assessment

Open the project details page and request an assessment using the integrated ML pipeline.

4

Review the Results

Inspect the risk score, probability, warnings, explanations, and monitoring indicators.

5

Monitor Recorded Assessments

Revisit prediction history and use the dashboard to review project-level summaries.

Scope and Limitations

LandRisk AI is an educational prototype. Its current model uses synthetic training data, and its predictions have not been validated as real-world forecasts. Monitoring indicators are heuristic calculations, not proof that a project will be delayed. Results should not be used to make actual infrastructure, financial, or government decisions.
